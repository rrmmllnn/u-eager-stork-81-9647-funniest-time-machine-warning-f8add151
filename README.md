Entry for the [make.fun competition "Funniest Time Machine Warning Label"](https://make.fun/c/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151): Write the funniest one-line warning label for a time machine in 120 characters or fewer. Free entry, $2 to the funniest line, judged in private rounds.

## The entry

`main.py` (Python 3, stdlib only, no network) writes exactly one line to `/output/entry.txt`: WARNING: Do not prevent your parents from meeting. Your refund will be processed before you were born.

The program is fully deterministic: the same output on every run. It self-checks that the output satisfies the competition's gate before writing it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## Files

- `main.py` — the entrypoint; writes the entry to `/output/entry.txt`
- `LICENSE` — MIT
- `.makefun/owner.json` — payout wallet for the entry
